# Homepage hero video (Remotion)

Self-contained Remotion workspace that renders the homepage hero loop into
`../public/brand/` (mp4 + poster). The site never depends on this package at
runtime; it only consumes the rendered files.

Format note: h264 mp4 only. At this bitrate the vp9 webm came out larger than
the mp4 AND hit Chromium decode errors in testing, so it earns nothing.

## Composition

9s muted loop, 1280x800 @30fps, four scenes over a slow-drifting decorative
background (drift is sinusoidal with period = duration, so the loop is
seamless):

1. **EmailMagnet** - the REAL extension popup (`public/emailmagnet-popup.png`)
   composited crisp over a fal.ai-generated soft-focus directory backdrop.
2. **Countdown321** - real product hero image + ticking countdown badge.
3. **ClickPilot AI** - excerpt of the real screen recording.
4. **Lockup** - the four product icons + "Software that ships."

Foreground UI is always a real asset. Generated images are decorative
backdrops only (truthfulness rule: never let a model render product UI).

## Commands

```bash
cd video
npm install
npm run studio   # live-edit the composition
npm run render   # renders webm + mp4 + poster into ../public/brand/
```

## Regenerating the fal.ai backdrops

Candidates are generated by `../scripts/generate-hero-assets.mjs` into
`video/assets/` (gitignored). The chosen ones are copied to `video/public/`
as `backdrop.jpg` and `geometry.jpg` (committed).

```bash
set -a; source /path/to/env-with-FAL_KEY; set +a
node scripts/generate-hero-assets.mjs
```

Never commit or print the FAL_KEY.
